# Dissertation

Guidance for Implementing the Project:

First, please ensure you have the file "kidney_disease.csv" downloaded and accessible.

1.Exploratory Data Analysis (EDA) and Data Cleaning:

Open the "EDA_and_Data_Cleaning.ipynb" file.
Execute the notebook to conduct Exploratory Data Analysis, visualizing the data's insights.
Perform the necessary data cleaning procedures.
Save the cleaned dataset as "clean_data.csv" for further use.

2.Applying Feature Selection and Model:

After obtaining the "clean_data.csv" from Section 1, proceed to the "Main.ipynb" file.
Execute the notebook to implement various feature selection methods and apply the classification model.
This file showcases the process of enhancing model performance through feature selection techniques.
